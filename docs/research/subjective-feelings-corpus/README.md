# 主观感受「靶子清单」三层公开调研

取样时间：2026-08-22（CST）  
性质：公开语料的定向取样与对表，不是频率普查，也不替無涘决定最终清单。

## 研究问题与编码边界

本调研检验的是：無涘已经押注的“最值得系统性拆解的主观感受”，在玩家语言、设计者行话和学界构念中分别能否找到可追溯的支撑；以及三层使用同一个词时是否真的在说同一件事。

- **A 层（玩家语言）**：玩家用来描述“玩起来是什么感觉”的名词、形容词或稳定短语。
- **B 层（设计者语域）**：创作者指称“要做出来的那个感觉”或紧邻它的制作行话。制作手段（如顿帧）与感受（如打击感）分栏，不混为同一层级。
- **C 层（学界术语）**：量表、分类框架、阶段模型或被游戏研究直接采用的情绪构念。动机、体验和设计启发工具性质不同，不能因词面相似就视为同一证据。

“好玩、无聊、神作、优化差、值不值”被编码为**总体评价或品质判断**，不计入主观感受靶子。理由是它们没有指出体验内容：两名玩家都说“无聊”，可能分别源于缺乏挑战、节奏拖沓或没有社交反馈。相反，“沉浸、紧张、失重、孤独、掌控”至少指向一种可进一步追问原因与设计杠杆的体验状态。这是本研究的编码规则，不是外部理论断言。

## 对表基线（原样保留）

無涘按品类给出的招牌感受：

- FPS → 枪感
- ACT → 博弈感、打击感
- ARPG/RPG → 代入感、成长感
- JRPG → 陪伴感
- Platformer/操作类 → 操控感 / 掌控感
- Racing/写实拟真 → 真实感
- Open World → 自由感 / 世界观（"真实的世界"）
- Horror → 恐怖（他自己标了问号，是全清单唯一疑问句）
- MMO → 社交感
- Strategy → 掌控感、宏观感
- 慢节奏 → cozy（舒适感）

Claude 补充的候选（来源=Claude 补充）：

顿悟感（Puzzle）、同步感（音游）、秩序感（模拟建造/工厂）、滚雪球/build 成型（Roguelite）、读心（格斗 PvP）、表达感（沙盒创造）、匮乏→稳定的翻转（生存）、后果感（叙事/VN）、在场感·孤独（走路模拟/氛围探索）。

## 明确的检索边界、失败与零结果

| 来源/查询 | 状态 | 应如何解释 |
|---|---|---|
| Reddit、B 站、X | 查询通道成功 | 精确词查询能返回正文或元数据；但这是排序取样，不是平台全量计数。X 的 `gamefeel` 单词查询有效，复合查询 `game feel juice weight readability` 大量返回无关内容，后者属于**查询语义失败**。 |
| Steam | 查询成功但非完整导出 | 可访问公开评测与讨论页；只取样可见结果，不推断全站词频。 |
| TapTap | 查询成功、定向样本 | 找到含“打击感/爽感/手感”“陪伴感”“沉浸感”“操控感/真实感”的直接玩家评测；这是精确词取样，仍不足以估计平台频率。 |
| B 站评论区正文 | **能力受限/查询失败** | 当前公开检索后端稳定返回视频标题、链接与播放量，未稳定返回评论正文。因此本报告的 B 站证据主要是视频标题和元数据；这不等于评论区没有相关词。 |
| 小黑盒 | **站点限定查询零结果** | `site:xiaoheihe.cn 游戏 打击感 手感 评测` 未返回可核验页面。零结果可能来自索引覆盖或查询式，不据此声称小黑盒不存在相关语料。 |
| YouTube 字幕 | **工具能力缺失** | 本地检索诊断显示 `yt-dlp` 后端未安装，未做字幕语料抽样；不是“没有英文视频”。GDC 以官网标题/摘要补位。 |
| `顿悟感 解谜游戏`（B 站精确搭配） | 查询成功、相关结果极少 | 只看到一个低播放直接命中；只能说本次样本中该**词形**不高频，不能说玩家没有顿悟体验。 |
| `陪伴感 JRPG`（B 站精确搭配） | 查询成功、未见直接 JRPG 命中 | 英文 Reddit 可见 companionship/camaraderie 叙述；中文精确搭配未被本次查询证实。标为“中文未查证”，不是“不存在”。 |
| `kama muta` + game/videogame | 查询成功、未找到直接游戏实证框架 | 找到一般心理学定义，也找到游戏中的 “being moved” 文献，但未验证两者被研究者直接等同。故游戏应用记“未查证”，而非“不存在”。 |
