# 待填充清单 · 可直接拷进 EGDS「主观感受」节

来源：2026-08-22 三层语料调研（`crosswalk.md` / `same-name-different-thing.md` / `existing-wheels.md`）+ 同日 EGDS 架构讨论。
**状态标记沿用 Alexander 星标法**：`★★` 跨案例比对过 ／ `★` 深入思考过但未跨案例 ／ `☆` 仅罗列，未系统化。
**当前真实盘点：★★ 0 条 ／ ★ 1 条（探索感）／ ☆ 其余全部。** 零星不是耻辱，是施工标记。

分类判据（2026-08-22 定）：**这个词与设计杠杆之间隔几层。**
隔 0 层（能直接列出杠杆）＝ **描述性感受**；隔 ≥1 层（必须先换成别的感受才能接杠杆）＝ **抽象感受**。

每条填充模板：

```
### <词>
- 状态：☆ / ★ / ★★
- 类别：描述性 / 抽象
- 英文对应：<英文语料里它被拆成什么；无对应则写「无单词对应」>

```

## 二 · 必须先拆义（同名不同物，不拆就会一条词条对应两套失败模式）

| 原词 | 拆成 | 判据差异 |
|---|---|---|
| **掌控感** | 身体操控感 `sensorimotor` / 系统掌控感 `systemic·epistemic` | 闭环尺度：毫秒—秒 vs 秒—多回合；失败词：input lag/floaty vs 不透明/不可解释 |
| **真实感** | 物理可信（重量） / 世界自治可信（living world） | 被判断对象：车该怎么动 vs 世界没有我也在运转 |
| **博弈感** | 系统博弈（对 AI/模式） / 人际博弈（对人 yomi） | 对手能否反向建模玩家；学习终点是「破解」还是「持续循环」 |
| **世界观** | → 建议退出主观感受层，改为 living world | 「世界观」通常指设定内容，不是感受 |

## 三 · 抽象感受（接不上杠杆，须先解析成上面那些）

不是废品——**它们是入口**，玩家只会给这些词。EGDS 第一段工作就是把它们解析下去。

| 词 | 英文 | 备注 |
|---|---|---|
| 好玩 / 有趣 | fun / interesting | thin evaluative（Williams）；scope 可自由伸缩：整个游戏 ↔ 一个机制 |
| 无聊 | boring | 同上，负向 |
| 爽 | satisfaction · power fantasy · catharsis · exhilaration · juiciness | 无单词对应；可拆（爽在哪里 → 打击感／压制／成长） |
| 心流 | flow | 「心流杠杆」不存在；Csikszentmihalyi 的条件是**别的感受的原因** |
| 沉浸感 | immersion / absorption / presence / engagement | 业界老大难；C 层已拆多构念 |
| 代入感 | identification | 与沉浸感中文常混用，英文分层清楚 |
| 社交感 | fellowship · community · relatedness · social presence | 过宽，须拆 |
| 恐怖 | fear / horror | **無涘唯一标问号的词**；同时是类型、总体情绪、多状态之和 |
| 敬畏 / 被触动 | awe / being moved / elevation | **语料带回的新候选**；有 awe 实验与 eudaimonic 综述 |
| cozy / 舒适感 | cozy · safety · softness · comfort | 無涘定归主观感受；按杠杆距离测偏抽象，**未决** |

## 四 · 中英不对称（这一栏本身就是靶子）

| 中文压缩词 | 英文展开 | 可直译 |
|---|---|---|
| 打击感 | impact · hit feedback · hit-stop · weight · punch · enemy reaction | 否 |
| 枪感 | gun feel + recoil · kick · snap · accuracy · perceived latency | 部分 |
| 手感 | controls feel · responsiveness · precision · weight · game feel | 否 |
| 爽感 | satisfaction · power fantasy · catharsis · exhilaration · juiciness | 否 |
| 代入感／沉浸感 | identification · absorption · presence · immersion | 否 |
| 博弈感 | mind games · yomi · reads · counterplay · pattern learning | 否 |
| 同步感 | in sync · entrainment · sensorimotor synchronization · flow | 存疑 |
| 后果感 | meaningful consequence · agency · reactivity · choice impact | 部分 |

反方向：**readability · agency · presence · juiciness** 在中文没有稳定单词无损对应。

## 五 · 架构词（**不要放在主观感受节下**，另置元层笔记）

这些管的是所有层怎么划分，混进主观感受会让下次读的人误以为它们是感受。

1. **感受 / 识别（描述）/ 理解（解构）/ 修改（重构）** —— 四步认知过程各自定义
2. **情绪曲线 / 情绪体验 / 主观感受 / 客观原因 / 设计杠杆** —— 五层各自的**入层判据**（现在只有名字没有判据）
3. **抽象感受 / 描述性感受** —— 判据＝与设计杠杆之间隔几层
4. **thin / thick 的中文定名** —— Bernard Williams《Ethics and the Limits of Philosophy》1985；语言学侧 Martin & White《The Language of Evaluation》2005（ATTITUDE → Appreciation）
5. **评价词（好玩／有趣／无聊）的位置** —— 建议不进栈，做入口索引
6. **既有轮子的位置** —— PLEX 22 类作**上位覆盖检查与漏项报警器**，非竞品；QF 12 动机同理

## 六 · 全局缺口（两个字段，目前 100% 空白）

- **失效条件**：每条词条「什么情况下它不成立」。没有这一栏，框架不可证伪。
- **uses**：谁用过这条、在什么项目、动了哪条杠杆、结果如何。没有这一栏，「没人用过」和「用过但没记」是同一个值＝空。
