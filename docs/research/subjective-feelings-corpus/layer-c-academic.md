# C 层：学界术语与成体系框架

框架之间测量对象不同：PLEX 是体验类别与设计工具，Quantic Foundry/BrainHex 偏玩家动机或类型，GEQ/PXI/PENS 偏一次游玩后的体验构念，GameFlow 是享受条件模型，Brown & Cairns 是沉浸阶段模型。下面保留这种差异，不把所有清单都当成同一种“感受分类学”。

## 框架总表

## Cozy games：有研究簇，没有统一“类目数量”

近期 cozy game 研究把安全、柔软、宁静、舒适、丰足/低匮乏等作为反复出现的体验或审美维度，但当前样本没有找到一个像 PLEX 那样被普遍采用的固定类别表。一项玩家研究将 cozy games 描述为易上手机制、亲社会叙事、低暴力，并关联 comfort、safety、abundance、softness。[Eludamos](https://eludamos.org/index.php/eludamos/article/view/7938)；另一研究聚焦 safety、softness、tranquility。[Springer](https://link.springer.com/article/10.1007/s44538-026-00003-y)

因此，`cozy = 舒适感` 只可作工作映射：cozy 更像由内容、节奏、风险结构和审美共同形成的体验簇，不能压成一个纯粹的愉悦刻度。

## Presence / immersion：不要把中文“沉浸”当单义词

- Brown & Cairns 的 engagement → engrossment → total immersion 是**投入深度阶段**。[来源](https://pmc.ncbi.nlm.nih.gov/articles/PMC6134042/)
- GEQ 把 sensory/imaginative immersion 与 flow、competence 等并列。[来源](https://research.tue.nl/en/publications/the-game-experience-questionnaire/)
- PENS 把 presence/immersion 与 autonomy、competence、relatedness、intuitive controls 并列。[来源](https://selfdeterminationtheory.org/player-experience-of-needs-satisfaction-pens/)

所以“代入感”“在场感”“沉浸感”至少涉及角色/想象认同、注意吸收和空间/媒介在场三个邻近但不相同的对象；本报告不给出未经验证的唯一中文译法。

## Awe、kama muta、elevation 与“被触动”

| 构念 | 游戏语境中的证据 | 本次判定 |
|---|---|---|
| Awe（敬畏） | 2024 年两项研究直接比较自然型与人性型 awe 在视频游戏中的体验与后果。[Communication Research](https://www.tandfonline.com/doi/abs/10.1080/03637751.2024.2397435) | 已进入游戏实证研究；是“宏大/超越”而非简单的正情绪。 |
| Elevation（道德提升） | 游戏中的 eudaimonic experience 综述把 elevation 与 awe、being moved 等并列。[Frontiers](https://www.frontiersin.org/journals/communication/articles/10.3389/fcomm.2023.1215960/full)；2025 沉浸式助人游戏研究也讨论 moral elevation。[Frontiers VR](https://www.frontiersin.org/journals/virtual-reality/articles/10.3389/frvir.2025.1716138/full) | 有游戏应用证据，但不是成熟通用玩家体验量表。 |
| Being moved / appreciation | 游戏研究把“悲伤但仍然很好”的感动体验视为独立满足来源。[Bopp et al., CHI 2015](https://www.researchgate.net/publication/275582808_It_Was_Sad_But_Still_Good_Gratifications_of_Emotionally_Moving_Game_Experiences)；综述同时列 meaning、self-reflection、nostalgia、awe 等。[Frontiers](https://www.frontiersin.org/journals/communication/articles/10.3389/fcomm.2023.1215960/full) | 有直接游戏证据；可能邻近陪伴、后果与叙事感动，但不与其同义。 |
| Kama muta | 一般心理学将其描述为共同体/亲密感突然增强时的 “moved/touched/heartwarming” 情绪。[Psychophysiology](https://onlinelibrary.wiley.com/doi/10.1111/psyp.13662) | `kama muta + game/videogame` 本次查询未找到可核验的直接游戏实证框架。**游戏应用未查证**，不能把一般定义直接移植为 C 层已覆盖。 |

## C 层对 EGDS 的意义

现成框架确实证明“约 10–22 个构念”的规模已有多个先例，但它们回答的问题不同：动机模型回答“为何来玩”，体验量表回答“这次玩后报告了什么”，设计框架回答“可以朝哪些体验构思/评估”。因此 C 层只能为候选提供邻近构念和测量警告，不能替代 EGDS 在“主观感受—客观原因—设计杠杆”之间建立可验证因果链。
