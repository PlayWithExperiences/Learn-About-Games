# EGDS 可逆选择与稳定地图设计

- 日期：2026-08-12
- 状态：已获发起人批准，可直接实施
- 范围：EGDS 桌面地图的节点选择、内容展开、关系查看与撤销

## 实际问题

当前一个点击同时触发三件事：展开叶容器、切换到 focus 布局、隐藏或移动大量框架节点。用户只是想查看一项，却看到整张地图重排；撤销又依赖独立的“返回全图”按钮。选择、展开与焦点被合并为一个不可预期的大状态变化。

## 状态模型

三种状态必须分离：

- 选择：当前用户正在查看哪个 Framework Node、Capability 或 Knowledge Topic。
- 展开：哪个叶容器的 Capability / Knowledge Topic 列表可见。
- 关系：当前选中实体的直接 supports / complements 关系。

选择不改变框架节点的坐标、可见性或结构线。展开也不重排总览。关系只增强相关边与端点。

## 桌面交互

- 点击 Framework Node 主体只选择节点并显示详情侧栏，不改变地图几何。
- 节点上的数量／展开按钮只控制该叶的实体列表；同一时间最多展开一个叶。
- 实体列表进入固定于地图右侧的详情侧栏，不作为第二张地图，也不改变基础框架布局。
- 点击 Capability / Knowledge Topic 后，同一侧栏切换为实体摘要、详情链接、资源链接与直接关系。
- 再次点击当前选中项、点击地图空白处、按 Esc 或点击侧栏关闭按钮都清除选择。
- “返回全图”不再是撤销必经路径；移除该按钮和 focus-layout 语义。

## 层级表达

总览始终保留统一的左到右父子方向。根、主分支、普通父子边和体验过程箭头继续使用不同线宽。选中只使用单一蓝色边框、局部结构线增强和侧栏标题，不依赖移动、隐藏或缩放节点制造焦点。

展开实体属于叶内容，不冒充 Framework Node。侧栏使用明确的“本组内容”标题和实体类型，不在地图内生成一条与框架同权重的新主干。

## 响应式与无 JavaScript

1227px 及以下继续使用原生层级大纲。选择与展开仍分离：`summary` 负责打开层级，实体“关系”按钮负责选择；再次按按钮或 Esc 清除。无 JavaScript 保留原生多开 disclosure、详情链接和关系文字等价物，不显示依赖脚本的选择侧栏。

## 验收条件

1. 桌面点击任意 Framework Node 前后 28 个 Framework Node 的位置和可见性完全不变。
2. 选择、展开和关系各有独立 DOM 状态，选择不会自动重排地图。
3. 当前选择可通过再次点击、空白点击、Esc 和侧栏关闭四条路径撤销。
4. 展开第二个叶会关闭第一个，但总览几何保持不变。
5. Career Lens 画像状态、个人进度和选择状态互不覆盖。
6. 1440px/1228px、Light/Dark、1024px/320px 与无 JavaScript 无横向溢出，键盘焦点可见且恢复合理。
