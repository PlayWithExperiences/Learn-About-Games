# 手感与反馈成长路径实施计划

## 目标

把设计稿落成一个可复核的 Astro 页面，并用测试锁住 100 条资料、EGDS 映射和跨页面链接。

## 步骤

1. 增加 `src/lib/learning-paths.ts`，定义六阶段合同和确定性选取函数。先以纯函数测试锁定阶段数量、总数、去重、主题归属和反转输入稳定性。
2. 增加 `/resources/paths/game-feel/` 页面和路径组件。页面只消费 Catalog，不改资源数据；每阶段显示目标、练习、产出、退出条件和资源链接。
3. 在资源导航增加“学习路径”入口，并为路径资源链接提供可复核的 `q` 查询回链。
4. 增加紧凑、响应式、暗色主题样式；原生 details 负责无 JS 可用性，脚本仅补充默认展开和阶段内展开全部。
5. 运行定向 Vitest、路径 E2E、`npm run check`、全量单测、构建和完整 E2E，人工检查桌面、移动和无 JS 页面。
6. 更新项目决策摘要、对话记录和 devlog，记录这是第一条路径试验，不把它宣传成完整课程。
