# Devlog 009：让成长资源可搜索，并扩展到 1100+

- 日期：2026-08-15
- 阶段：Private 本地候选，未发布

## 这轮解决什么

成长资源已经不适合只靠逐行滚动浏览。本轮保留 15 个主题子表、展开全表与七维事实筛选，并新增一个可分享的搜索框：标题、简介和来源会以中英文文本参与匹配，输入会做 NFKC 归一化，搜索词写入 `q` 参数，reload、history back 和无 JavaScript 页面都保持可信。

Work Item 行改成更窄的编辑型目录：主信息、事实列和访问入口仍分开，但减少留白、边距和字号，让桌面展开态一次看到更多条目；移动端继续用单列，避免为了密度牺牲阅读顺序。

## 500 条扩展的边界

本轮新增 500 个 Work Item，全部来自 GDC Vault 官方 sitemap 与逐条会话页。每条都按 GDC play ID 与规范化 canonical URL 去重，保留官方标题、英文原始语言、`talk` 媒介、`subscription` 访问方式和检查日期。GDC 的订阅边界没有被写成免费，也没有把搜索摘要、聚合页或完整录播可用性冒充证据。

这批资料以英文为主，和用户指定的资源优先级一致；已有中文条目不被覆盖，下一轮继续优先寻找能直接核验的中文课程、文章与研究页面。日文维持较低优先级，只在原页证据明确且能补足缺口时收录。

## 当前规模与维护原则

目录由 610 增至 1110 个 Work Item，41 个 Source、1124 个 Access Version 和 15 个 Resource Topic。数量不是评分，也不是推荐顺序；每个条目仍必须有唯一主要主题、可核查访问版本和规范化 URL。后续扩展将继续按来源证据、语言可消费性与能力覆盖去重，而不是为了达到数字填入未经核验的页面。
