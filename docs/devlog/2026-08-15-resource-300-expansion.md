# Devlog 008：把成长资源扩到 300+，优先英文与中文

- 日期：2026-08-15
- 阶段：Private 本地候选，未发布

## 目标与取舍

这一轮把“至少 300 条”作为内容规模目标，但不把数量当作质量、推荐或学习顺序。英文与中文优先；日文只在已有明确原页、能补足研究缺口时纳入。每个 Work Item 仍必须有唯一规范化 canonical URL、一个主要 Resource Topic、可核查访问版本与检查日期。

## 本轮结果

净增 385 个 Work Item，目录达到 41 个 Source、610 个 Work Item 与 624 个 Access Version。新增内容主要来自 GDC Vault 与 Game Developer 的英文一手会话／文章，以及 Level Design Book、Game AI Pro、Game Accessibility Guidelines、MIT OCW、Atlassian 与公开课程原页；中文补入腾讯游戏学堂条目，日文只保留 J-STAGE 研究条目。扩展批次的研究 notebook 保存在 `docs/research/2026-08-15-resource-300-intake.md`。

本轮语言统计为原始语言 en 555、zh-Hans 38、ja 17；可消费版本对应 en 567、zh-Hans 40、ja 17。媒体与主题分布不追求平均：资源多的关卡空间、叙事表达与设计基础反映可核验材料的实际密度，资源少的从业者与领导主题仍继续补缺。

## 证据边界

GDC Vault 会话保守标记为 subscription；公开 session metadata 或 slides 不被表述为完整录播免费。Exa 在本轮检索中遇到配额限制后停止重试，后续以 Jina Reader、官方页面与可访问原页复核；没有把搜索摘要、聚合页、失效证书页面或无法确认标题的候选写入 catalog。发现一条规范化 URL 与既有 Work Item 重复后按规则排除，最终净增为 385 而不是把重复计入 386。

后续仍会继续补充主要英文作者、GDC 与学术资料，同时收集可核验中文资料；资源总量只说明覆盖范围，不改变能力地图、EGDS 或职业标签的语义。
