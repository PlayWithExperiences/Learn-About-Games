# 为成长路径增加可重叠的关注面

## 背景

“手感与反馈”路径已经把 100 条资料分成六个阶段，但同一条资料往往同时涉及玩法、叙事、美学、实现或研究。把资料强行归到单一类别会遮住这种相互支撑的关系，也会让路径看起来过于庞杂。

## 决策

保留六阶段作为主要阅读顺序，在路径顶部增加可叠加的关注面：玩法与挑战、叙事与表达、美学与表现、技术与实现、研究与验证，以及跨支柱。每条资料可以拥有多个关注面；“跨支柱”只标记同时连接玩法、叙事和美学三条核心支柱的资料，不把支持面误当成第四条核心支柱。

筛选只改变当前显示的资料，不改变阶段配额、资源顺序或 EGDS 对应关系。技术与研究是支持面，三条核心支柱仍然可以重叠；无 JavaScript 时所有资料和禁用控件仍可读。

## 验证

- 纯函数测试锁定七个关注面、100 条资料的标签闭包和逆序输入稳定性。
- Chromium 与移动端覆盖全部／关注面筛选、计数更新、清除回全部、无 JavaScript 说明和横向溢出。
- `npm run check`：0 errors / warnings / hints；全量 Vitest：184/184；静态构建：143 pages；路径定向 E2E：10/10。

这次没有新增评分、完成率或唯一学习顺序；关注面只是帮助读者从同一条作者化路径中取出当前更关心的材料。
