# 让创新地图先讲清历史，再打开证据

日期：2026-09-12

旧版已经有作品、机制事件与文献，但三种视角拆开了彼此的上下文。没有语义的纵向排布也让读者难以看出不同发展脉络。此次重做 `/atlas/`，让同一份数据先成为可比较的历史总览。

总览横向按年代分列，纵向分为九个阅读区域。区域不是排他的品类归属：Dead Cells 等跨界作品只放一次，关系与标签保留交叉。列内显示实际年份并排序；网格间距不代表时间长度，创新观察的日期也不宣称“首次发明”。

读者可以从“失败之后，什么留下来”“空间怎样成为玩法”“从通关到生活在世界里”三个问题进入。它们是作者化比较阅读，不自动创建影响关系。选择对象后显示直接相邻的关系，来源面板能继续点击另一端，浏览器返回可恢复选择；搜索和区域选择保留全图位置。

原来按精确年份定位、可缩放与平移的网络保留在 `/atlas/network/`，与新总览共享 catalog。不是另建一个图数据库，也不让两个页面维护两份历史事实。年代目录是静态 HTML，在没有 JavaScript 时仍能阅读对象、关系与来源。

新增十二个历史对象，补入 M.U.L.E.、Tetris、John Madden Football、Myst、Grand Theft Auto、EverQuest、The Sims、EVE Online、World of Warcraft、Nintendo Wii、Portal 与 Minecraft。来源是 [Computer History Museum 的 Graphics & Games 年表](https://www.computerhistory.org/timeline/graphics-games/)和 [The Strong 的游戏史年表](https://www.museumofplay.org/video-game-history-timeline/)中本轮读取的对应条目。Minecraft 的 2009 明确指早期公开版本，不是 1.0 正式发行。

此次没有依据年表相邻关系新增影响边。数据为 96 个对象、86 条关系、78 项 Evidence；既有证据保留原核查日期，没有假装本轮重新访问过全部文献。材料仍偏欧美和日本；格斗、节奏、竞速、移动和中国游戏史存在明显缺口，2020 年之后也远未覆盖。下一步应围绕这些缺口做有界的专题史料核查，而不是继续堆叠未经证明的连线。
