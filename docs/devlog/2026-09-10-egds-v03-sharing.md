# 同步 EGDS v0.3，重新打开分享入口

日期：2026-09-10

Learn About Games 已经积累了 5,437 项资源、44 个来源和 5,590 个访问版本。作者决定把现有地图、资源与创新沿革重新开放分享，继续在真实使用中修订。

公开前，我们向 EGDS 项目核对了最新方法定义。当前名称为“体验型游戏设计系统 / Experiential Game Design System”。感知、理解、归因、重构是四个认知过程；体验形态、主观感受、感受诱因、设计杠杆是四类内容。体验曲线、段落、循环、瞬间则表示从整体到局部的观察尺度。

介绍页、能力地图、首页和学习路径的对照同步采用 v0.3。分析从已有体验出发，设计从期望体验出发；设计师创造的是让体验发生的场域和舞台。叙事、玩法与挑战、美学可以相互增强，关联本身不代表普遍因果或已经验证的效果。

旧文章标题继续保留“情感化”等历史名称。地图中的生产、团队、产品与更广语境是本站的扩展，不与 EGDS 核心四层混为一谈。现有能力、资源与关系保持不变，稳定深链继续可用。

EGDS 的方法论版本与本站软件版本分别记录；此次同步不意味着已经完成整个知识库，也不把资源数量当作质量评分。后续继续依据作者版本、来源证据和使用反馈更新。
