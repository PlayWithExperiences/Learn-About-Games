# Devlog 004：把探索入口重新合到一起

- 日期：2026-08-11
- 阶段：Private 本地候选，未发布

## 为什么继续改

EGDS 已经让能力地图拥有作者化骨架，但独立的“职业方向”页面仍复制了一整张地图；资源目录虽然信息完整，128 条内容仍形成很长的页面；Innovation Atlas 有缩放按钮，却不像用户熟悉的地图那样连续响应滚轮和拖动。问题不是再增加一个入口，而是让已有信息在需要时出现。

## 这轮改变了什么

- 三个 Career Lens 变成能力地图中的职业标签。标签只改变同一张 EGDS 地图的强调；选中后，映射、依据、限制、复核日期和来源就在标签旁边出现。旧职业 URL 只做兼容跳转。
- 成长资源默认显示 15 个主题子表。用户可以只展开一个主题，也可以展开全表后按主题、知识议题、能力、语言、媒介、访问方式和 Source 筛选。20 个 Source 保留独立目录，128 个 Work Item 不因分组而复制。
- Innovation Atlas 增加显式地图模式。没有进入模式时，滚轮继续滚动页面；进入后，滚轮围绕指针连续缩放，拖动负责平移，Esc 退出。中间宽度、移动端和无 JavaScript 继续使用完整时期大纲。
- 早期电子游戏史加入 Tennis for Two、Spacewar!、Brown Box、Galaxy Game、Computer Space、Magnavox Odyssey、Odyssey Table Tennis 与 Pong 等节点。实验装置、实验程序、系统原型、商业硬件和 Game 不再被画成同一种对象。

## 证据边界

Pong 是 1972 年重要的商业突破，但不是不加限定的“第一款电子游戏”。时间相邻不会自动产生影响关系；例如，没有证据支持的 Tennis for Two → Pong 没有被连线。参与者口述支持的 Odyssey Table Tennis → Pong 保留为较谨慎的 credible 关系，而不是升级成无争议事实。

## 下一步

继续补充早期商业化、家用系统和 arcade 分化的节点与一手资料；继续扩充资源覆盖和语言版本；用真实触控板长期检验 Atlas 地图模式。仓库仍保持 Private，Pages 仍禁用，这轮只提供本地预览，不冒充公开发布。
