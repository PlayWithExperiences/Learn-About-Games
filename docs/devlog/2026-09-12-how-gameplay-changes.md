# 从模组、三维空间到口袋里的游戏

日期：2026-09-12

Innovation Atlas现在有195个历史对象、160条关系和172项来源。七个比较入口分别从单局、空间、世界、模组、音乐表演、技巧练习和移动平台提出问题；所有入口仍使用同一份目录。

这次补全更关注变化的具体内容。BuildCraft的首版只有管道，采矿、自动合成和动力系统随后才出现；Factorio作者明确承认受到它的启发。[维护者回顾](https://blog.asie.pl/2015/01/buildcraft-history-and-design/)与[Factorio作者说明](https://www.factorio.com/blog/post/fff-50)承担不同的证据职责。

二维和三维之间也不是简单的替换。[任天堂开发者访谈](https://www.nintendo.co.jp/3ds/interview/arej/vol1/index2.html)讨论了3D Land如何用明确终点回应三维探索的迷路感，同时通过隐藏收集保留探索。地图把这样的设计回应和直接影响分开。

移动平台的路线比较掌机移植、按键手机、触屏以及现实位置玩法。新的中文作品包括古剑奇谭系列对照与戴森球计划；近期节点包括2025年的Hades II正式版、Expedition 33，以及2026年的Slay the Spire 2抢先体验。作品进入地图不意味着其长期影响已经得到证明。

我们保留版本语境：DotA的创作阶段与公开版本分开，Fruit Ninja HD的2012年条目是功能实例，古剑3采用明确的Steam版本日期。相似的玩法不会自动得到继承箭头。更多地区、早期前身、体育传统和尚未核查的跨作品关系仍需继续补充。
