# Devlog 007：增加证据深度与选择性品类谱系

日期：2026-08-13

这一轮继续做两件看似都是“加内容”、但证据结构完全不同的工作：扩大成长资源目录，以及为 Innovation Atlas 增加第一人称射击和即时战略谱系。

成长资源新增 16 个 Work Item：7 条 GDC Vault 原始会话和 9 篇 Game Developer 作者文章。它们主要补充原型、玩法测试、生产协作和系统设计。当前目录为 38 个 Source、225 个 Work Item、239 个 Access Version。数量不是评分；每个 Work Item 仍必须有唯一主要资源主题、可核查 canonical URL、访问方式和检查日期。

Atlas 新增 10 个节点、6 条有向关系和 8 项 Evidence，总量成为 58／42／69。Shooter 与 RTS 在界面上是两条新的证据透镜，但透镜只改变强调，不隐藏、不重排也不移动全局网络。Maze War 可以作为早期第一人称空间表现的上下文，却不能仅凭年代被连到 Wolfenstein；Dune II 可以说明现代 RTS 约定的主流化，却不能被无条件写成“第一款 RTS”。

内容增加也暴露了一个交互真实性问题：更高的 Atlas 画布使旧的 50% 缩放下限无法完整容纳场景。“适应全图”现在以完整可见为第一语义，必要时允许低于手动加减按钮的 50% 下限；手动缩放仍保持 50%–200%。

下一步不是追求每个 Genre Family 数量相同，而是继续扩大可核查覆盖：先找来源，再决定节点；先确认具体关系，再画边。空 Family 继续诚实显示“待研究”，不会用相邻年代或常见说法填满。
